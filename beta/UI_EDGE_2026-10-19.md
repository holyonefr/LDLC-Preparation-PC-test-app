# Texte de progression et fausse alerte Edge — 19 octobre 2026

Périmètre : bêta LDLC uniquement, conformément au gel des trois productions.
La photo utilisateur montre l'Addon ; aucune nouvelle version Addon n'est publiée.

Les deux lignes sous la barre sont agrandies : message bleu de 15 à 18 unités
(minimum 8,5 au lieu de 7), texte clair de 11 à 14 (minimum 7,5 au lieu de 6).
Les rectangles sont ajustés pour conserver l'écart et le bouton Quitter.

Cause de la fausse alerte : AppsFolder énumère toutes les applications installées.
Le retrait de l'épingle Edge ne retire pas Edge d'AppsFolder ; l'ancien contrôle
considérait donc le retrait réussi comme un échec. La recherche porte maintenant
sur les raccourcis réellement présents dans le dossier TaskBar et sur le verbe
Shell de désépinglage français/anglais. Une épingle encore détectée après retrait
garde son avertissement. Une erreur de lecture Shell n'est pas traitée comme
une absence. Edge ouvert est une information, pas une preuve d'échec du retrait.
Le navigateur Edge n'est pas désinstallé et ses processus ne sont pas arrêtés.

Comparaison locale avec le vrai module historique du commit `0b02a77` :

- Avant : le scénario Edge installé mais non épinglé reproduit la fausse alerte,
  code de test 1 attendu.
- Après : huit scénarios réussis, code 0 : application installée sans épingle,
  retrait anglais et français accentué, refus réel, raccourci persistant ou
  retiré, lecture Shell impossible et arrêt demandé.
- Syntaxe et contrôles de branding réussis. Les opérations Shell sont simulées,
  aucun bureau réel n'est modifié pendant ces essais.

Le test de non-régression est intégré à la suite release Windows.
